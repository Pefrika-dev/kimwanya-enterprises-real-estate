# Kimwanya Enterprises — website and property register

A mobile-first website for **Kimwanya Enterprises**, a property and multi-agency business in Migori and Kehancha, Kenya.

Built by [Thomas Hondo Chacha](https://thomashondochacha.co.ke/). This was prepared without a commission from the business. There is no invoice and no payment pressure. The business owner decides whether to keep, change or remove it.

## Live site

`https://kimwanya-enterprises-real-estate.vercel.app/`

## Photography

The site uses the original local imagery kept in `assets/images/`. No Facebook-sourced images are used. Images are presented as general area/property views only — no image is proof of ownership, title, price or a specific transaction.

## Local register

`admin.html` is a private working register stored in this browser. It is not linked from the public pages. Local access password: `kimwanya2026`.

To publish a listing, add it in the register and set its status to published. To clear the register, use **Reset Register**. Data is kept in browser LocalStorage under keys prefixed with `kimwanya_`; clearing site data starts fresh.

## Contact flow

The enquiry forms open WhatsApp with the message already written. Nothing is stored by the website and no payment is requested.
